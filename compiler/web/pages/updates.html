Update to the newest release

The router downloads the newest rollgate release and installs it into a copy of its system; the running system isn't changed. Then it restarts into the new release once, as a trial. If the trial's health checks don't pass within 5 minutes, it goes back to this release by itself.

Downloading can take several minutes. Keep this page open until it answers; the router then restarts and is away for a few minutes. Your settings are kept.

Go back to the previous release

After an update, the release from before it is kept. Going back makes it the system again and restarts the router into it. The release you leave is kept in turn, so you can come back to it the same way.
